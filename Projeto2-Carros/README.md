Atividade
Considere o cenário abaixo e faça a atividade.
1) Crie um projeto Java na IDE VSCode.
2) Crie todas as classes com todos os respectivos relacionamentos, atributos, métodos, get e
set e construtores.
3) Crie os métodos salvar, alterar, excluir e pesquisar em cada classe.
4) Para cada método de cada classe, apenas mostre uma mensagem dizendo que o tal
método foi executado.
5) Crie uma classe contendo o método main.
a) No método main, faça:
i) Crie objetos a partir das classes identificadas no passo 2.
ii) Atribua valores aos atributos dos objetos.
iii) Execute os métodos de cada classe.
iv) Execute a aplicação para validar o funcionamento
